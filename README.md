# 语言学习平台

一个现代化的多语言在线学习平台，提供沉浸式的语言学习体验。

## 功能特性

### 📚 分级课程体系
- 支持英语、日语、韩语等多种语言
- 从入门到高级的分级课程
- 丰富的课程内容和学习资源

### 🎮 互动学习模块
- **单词记忆**：闪卡式学习，强化记忆
- **语法练习**：多种题型，巩固语法知识
- **口语跟读**：发音练习（开发中）
- **听力训练**：听力理解练习（开发中）

### 📊 学习进度追踪
- 详细的学习数据统计
- 成就系统和徽章奖励
- 学习曲线和进度可视化

### 👥 社区交流
- 动态分享学习心得
- 问答社区互助学习
- 点赞评论互动

### 🎯 个性化学习
- 个性化学习路径推荐
- 用户偏好设置
- 学习目标设定

## 技术栈

- **前端框架**：React 18 + TypeScript
- **路由管理**：React Router DOM
- **状态管理**：Zustand
- **样式方案**：Tailwind CSS
- **构建工具**：Vite
- **图标库**：Lucide React

## 快速开始

### 安装依赖

```bash
npm install
```

### 启动开发服务器

```bash
npm run dev
```

应用将在 `http://localhost:3000` 启动。

### 构建生产版本

```bash
npm run build
```

### 预览生产版本

```bash
npm run preview
```
